# Hackathon starter

React + TypeScript placeholder with a light-purple/white theme.

## Run

```sh
npm install
npm run dev
```

## Check

```sh
npm test
npm run build
```

## Pages

- `#/login`: demo form and an **Explore the demo** shortcut.
- `#/dashboard`: skeleton summary, chart, and list placeholders.
- `#/feature-1`, `#/feature-2`, `#/feature-3`: blank skeleton pages.

This is a frontend preview, not real authentication. The form accepts a valid email format and any password of at least eight characters. Use made-up values: neither field is stored or sent. Direct page links are intentionally public.

The skeletons are permanent preview shapes, not a pending request. Their animation respects reduced-motion preferences. No backend, database, or feature logic is included.

The implementation follows Impeccable's visual guidance and uses 21st's local design context and review. 21st catalog retrieval required sign-in and was not used. Styling uses plain CSS, native form controls, Manrope, and Lucide icons.

Files in `sources/` are synced reference material and are not modified by this starter.
